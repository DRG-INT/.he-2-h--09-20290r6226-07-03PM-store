# FreeDOS – Modern DOS Kompatibilis Rendszer
Verzió: 1.0-stable
Forrás: UNICAGD-Core Analízis
Státusz: HASZNÁLHATÓ

## 1. Mi az a FreeDOS?
A FreeDOS egy nyílt forráskódú MS-DOS kompatibilis operációs rendszer. 1994-ben indult, és ma is aktív fejlesztés alatt áll. Célja, hogy a régi DOS alkalmazások futtathatók legyenek modern hardveren.

## 2. FreeDOS Architektúra

### 2.1 Kernel
- MS-DOS kompatibilis kernel
- 16 bites és 32 bites mód támogatása
- BIOS és UEFI rendszereket is támogat

### 2.2 Parancsértelmező
- COMMAND.COM kompatibilis parancsértelmező
- DOS parancsok támogatása
- Batch fájlok futtatása

### 2.3 Eszközmeghajtók
- MS-DOS eszközmeghajtók kompatibilitása
- SCSI, USB, LS-120 támogatás
- Grafikus kártyák támogatása

### 2.4 Fájlrendszerek
- FAT12, FAT16, FAT32 támogatás
- NTFS olvasás támogatás
- ISO 9660 támogatás

## 3. FreeDOS és a mai világ

### 3.1 Alkalmazások
- Régi DOS játékok futtathatók
- DOS alkalmazások futtathatók
- DOS fejlesztői eszközök

### 3.2 Hardware támogatás
- Modern gépeken fut
- USB eszközök támogatása
- Hálózati kártyák támogatása
- Grafikus kártyák támogatása

### 3.3 Közösség
- Aktív fejlesztés
- Open Source (GPL licenc)
- Közösségi támogatás

## 4. FreeDOS telepítés

### 4.1 Live CD
- FreeDOS Live CD elérhető
- Telepítés nélküli futtatás
- ISO kép letöltése

### 4.2 Floppy disk
- 1.44 MB-os floppy disk kép
- Régi gépekre telepítés

### 4.3 Hardveres telepítés
- FAT partícióra telepítés
- Bootloader beállítása

## 5. FreeDOS és a Windows kernel kapcsolata
- A FreeDOS a DOS-ból származik
- A Windows 9x/ME a DOS-ra épült
- A Windows NT/XP/7/8/10/11 nem DOS-alapú
- A FreeDOS nem Windows kompatibilis

## 6. FreeDOS és a Linux kernel kapcsolata
- Nincs közvetlen kapcsolat
- A FreeDOS saját kernelje van
- A Linux kernel nem DOS-alapú

## 7. FreeDOS driver fejlesztés
### 7.1 Driver model
- MS-DOS eszközmeghajtók kompatibilitása
- INT 13h, INT 21h API
- BIOS megszakítások

### 7.2 Driver írás
- Assembly és C nyelven
- DOS API használata
- BIOS megszakítások használata

## 8. FreeDOS és a biztonság
### 8.1 Hozzáférési szabályok

### 8.2 Veszélyeztetettség
- Nincs memóriavédelem

## 9. FreeDOS és a Plan 9
- Nincs közvetlen kapcsolat
- A FreeDOS a DOS-ból származik

## 11. FreeDOS tanulságai
- A DOS ma is használható

## 12. Összefoglalás
A FreeDOS egy nagyon jó, stabil, használható DOS kompatibilis rendszer. A régi DOS alkalmazások futtathatók modern hardveren. A FreeDOS a DOS öröksége, nyílt forráskódú formában.
